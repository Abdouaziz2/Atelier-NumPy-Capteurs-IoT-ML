# Atelier NumPy — Capteurs IoT

Atelier pratique consacré à **NumPy** dans le cadre de la formation Python pour le Machine Learning et l'IA.

Le scénario porte sur l'analyse de données issues de capteurs IoT mesurant notamment la température dans différents bâtiments.

L'objectif de l'atelier est de découvrir et mettre en pratique les principales fonctionnalités de NumPy pour la création, la manipulation et l'analyse de données numériques.

## Objectifs de l'atelier

- Manipuler des tableaux NumPy
- Explorer et indexer des données
- Utiliser le slicing et le filtrage booléen
- Manipuler des matrices
- Effectuer des calculs statistiques
- Découvrir la vectorisation et le broadcasting
- Préparer des données pour de futurs traitements de Machine Learning

## Technologies

- Python
- NumPy
- Jupyter Notebook

## Livrable

Le travail sera réalisé dans le notebook :

`atelier_numpy_iot.ipynb`

## Contexte

Les données simulées représentent des mesures provenant de plusieurs capteurs IoT.

Elles seront progressivement manipulées et analysées afin de comprendre comment **NumPy peut être utilisé comme outil de base pour la Data Science et le Machine Learning**.
